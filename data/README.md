# Данные

В проекте используется датасет **School of Analytics Open Hackathon 2026**.

Исходные CSV не включены в репозиторий. Это уменьшает размер репозитория и не создаёт предположения о наличии права на повторное распространение материалов организаторов.

Для воспроизведения анализа необходимо получить датасет у организаторов и разместить таблицы в директории:

```text
data/raw/soa_hackathon_2026_marketplace_dataset/
```

Ожидаемая структура:

```text
data/raw/soa_hackathon_2026_marketplace_dataset/
├── users.csv
├── experiment_assignments.csv
├── sessions.csv
├── impressions.csv
├── clicks.csv
├── orders.csv
├── products.csv
├── sellers.csv
├── premium_subscriptions.csv
├── support_tickets.csv
└── data_dictionary.csv
```

Описание полей содержится в предоставленном организаторами `data_dictionary.csv`.

Данные не являются частью авторского кода этого репозитория и не распространяются вместе с проектом.
